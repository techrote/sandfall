# CyberSand licensing status

No public license has been selected for original CyberSand source, assets, or
documentation. The private repository is therefore not a grant of permission
to redistribute, sublicense, or publish that original work.

This does not alter the licenses of third-party components. Their copyright,
license, attribution, source revision, and redistribution records are preserved
in `THIRD_PARTY_NOTICES.md`, the vendored add-on directories, and dependency
lock files.

Before any public release or third-party distribution, the owner must select a
project license, confirm ownership/contributor permissions, and review the
release bundle against all third-party terms. Private GitHub migration and CI
are intentionally not blocked on that future decision.
